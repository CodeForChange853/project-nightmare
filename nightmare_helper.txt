Last Updated: 2026-10-20

HOW TO SPEAK TO NIGHTMARE & CUSTOMIZE VOICE
- Open http://127.0.0.1:<NIGHTMARE_PORT> (or :5173 in dev mode) in GOOGLE CHROME.
- Hold down the [Space] key (or hold the "Hold to Talk" button) while speaking,
  then release when finished.
- Toggle Google Web Speech recognition language between `mic: en-PH` (Philippine
  English) and `mic: en-US` in the top status bar.
- Toggle AI reading voice between Male and Female (`voice: male` / `voice: female`
  in the top status bar, or say "switch to female voice" / "switch to male voice").
- Change AI reading speed (`speed: 0.9x / 1x / 1.15x / 1.3x / 1.5x` in the top
  status bar, or say "speak faster" / "speak slower" / "normal speed").
- Nightmare automatically reads its full generated replies aloud sentence-by-sentence
  (and every reply in the terminal log also has a `read aloud` button + `stop reading`
  button while speaking).

HOW SPEED & MODEL TIERS WORK
- Tier 0 (Instant Python — <10ms, 0 model calls, uses no quota):
  Greetings, time/date, help, listing projects, git branch/status, live weather,
  adding/listing/completing/deleting reminders, opening apps/folders/websites,
  the database viewer, reading short (<400 char) .md/.txt files, and cached
  handoff summaries.
- Tier 1 (Fast — `gemini-3.8-flash-low`, ~7-8s):
  Single-project `handoff.md` and README summaries, longer `.md`/`.txt` document summaries,
  and general questions.
- Tier 2 (Deep — `gemini-3.8-flash-high`, slower than Tier 1):
  Cross-project comparisons ("which project needs attention?") or whenever you
  include "think deeply", "analyze deeply", or "use smart model".
- Gemini 4 Argon is not used. Change models with AGY_FAST_MODEL / AGY_SMART_MODEL
  in backend/.env (list the choices with `agy models`) and restart the backend.

CONVERSATION MEMORY & SESSIONS
- Nightmare remembers your last 6 exchanges in this login, so follow-ups like
  "and what about the second one?" work in general questions.
- Memory lives only in the running backend: it is forgotten after 30 minutes of
  silence, when the backend restarts, or when you start a new session.
- New session: say "new session" / "clear the conversation" / "start over",
  or type /clear or /new. This also clears the conversation on screen.

LONG-TERM MEMORY (laptop and phone can read; only the laptop can change it)
- Facts: "remember that my defense is in March" / "keep in mind that I like dark mode".
  Reminders still use "remind me to ..." or "remember to ...".
- Hear them: "what do you remember" / "what have I told you" / "list my memories".
- Remove one: "forget that my defense is in March" or "forget memory 3" (one at a time).
- Facts stay until you forget them. They also show, with a Delete button, in the
  database panel (tab Memory).
- Saved conversations: your questions and answers (not PIN, database, settings, shell
  or reminder commands) are kept in the local database for 90 days. Older days are
  condensed into a short summary in the background. Only the memories related to your
  current question go into the model's prompt.

SLEEP & WAKE
- After 5 minutes with no clicks, keys or replies, Nightmare falls asleep: the
  graph folds away, the eye closes and the title reads "Sleeping". It never
  sleeps while it is thinking, speaking, or a dialog is open.
- Sleep now: say "go to sleep" / "good night", or type /sleep.
- Wake: hold Space and say "Nightmare, wake up" (also "hey nightmare wake up").
  It answers "Hello, Nightmare is awake. What are we going to do today?" and the
  graph opens again. Any other command also wakes it and runs as usual.
- Sleep and wake are handled in the browser and use no model calls.

GRAPH HIGHLIGHTS
- When a reply is about a node, the graph switches to it, flashes its count, and
  sends a spark from the eye along the line to that node. When it is about one
  item (for example "what is the progress of citizengraph"), the spark continues
  to that project, the arc scrolls to it, and it is selected in Details.
- Reminders, Projects, Apps, Tasks and Quick asks (weather, usage) all do this.

TYPED SHORTCUTS (TYPE "/" IN THE COMMAND BOX)
- /help       show this command list (or say "help" / "what can you do")
- /clear      clear the conversation and start a new session
- /new        same as /clear
- /reminders  read your reminders
- /db         open the database (asks for your PIN)
- /sleep      put Nightmare to sleep until you say "Nightmare, wake up"

1. PROJECT PROGRESS & HANDOFF SUMMARIES
-------------------------------------------------------------------------------
Purpose: Finds a project folder on your Desktop, reads its `handoff.md` safely,
         and summarizes current status, recent work, next steps, and blockers.
         Repeat checks on an unchanged file return instantly from cache.

Voice / Text Commands:
  - "progress of bims"
  - "what is the status of citizen graph"
  - "progress of project nightmare"
  - "how is bims going"
  - "check on bims"
  - "what's going on with bims"
  - "what is next for bims" / "what's the next task in citizengraph"
  - "go to my desktop, find project bims and tell me the progress"

If a project has no handoff.md, Nightmare says so and tells you what git knows
instead (branch, uncommitted files, last commit).

-------------------------------------------------------------------------------
1b. WHAT A PROJECT IS ABOUT (README)
-------------------------------------------------------------------------------
Purpose: Reads the README.md (or readme.txt) at the top of a project folder and
         says what the project is, who it is for, and what it is built with.
         With no README it uses handoff.md instead. Repeat asks are instant
         until the file changes.

Voice / Text Commands:
  - "what is citizengraph all about"
  - "what's bims about"
  - "tell me about project nightmare"
  - "what does citizengraph do"
  - "describe bims"

12. USE NIGHTMARE FROM YOUR ANDROID PHONE (READ-ONLY, OVER TAILSCALE)
-------------------------------------------------------------------------------
Purpose: Talk to Nightmare from your phone anywhere, through your private
         Tailscale network (HTTPS, only your own devices; never the public
         internet). Phone sessions are ALWAYS read-only, even if you type the
         laptop PIN: progress, about, projects, git status, documents, weather,
         reminders and chat work; opening apps/folders, running tasks,
         approving dialogs and the database viewer do not.

One-time setup (on the laptop, PowerShell in the project folder):
  1. Install Tailscale on the laptop (winget install --id Tailscale.Tailscale)
     and on the phone (Play Store), signed in with the same account.
  2. In the Tailscale admin console, DNS page: MagicDNS on, HTTPS Certificates on.
  3. Set NIGHTMARE_PHONE_PIN in backend/.env (6+ digits).
  4. .\scripts\setup_tailscale.ps1 -Restart
     It prints the phone address, e.g. https://laptop.tail1234.ts.net/

On the phone:
  - Open that address in Chrome, log in with the phone PIN.
  - The tab bar at the bottom: Talk / Projects / Reminders / Chat.
      Talk       hold the big eye and speak; the answer appears right under it,
                 with Read aloud / Stop; quick asks are buttons below.
      Projects   search box + list; tap a project for its page (Read progress,
                 What it's about, Git status). Android's back gesture closes it.
      Reminders  your open reminders with a Done button.
      Chat       the whole conversation and the text box.
  - Chrome menu > "Add to Home screen" gives Nightmare its own icon.

Laptop commands:
  - .\scripts\setup_tailscale.ps1 -Status   what is being shared
  - .\scripts\setup_tailscale.ps1 -Off      stop sharing (add -Restart to apply now)

-------------------------------------------------------------------------------
13. SMALL ALWAYS-ON-TOP WINDOW (CTRL+ALT+N, LAPTOP)
-------------------------------------------------------------------------------
Purpose: Summon a small Nightmare window over whatever you're doing, from any
         app. A little helper (backend\hotkey.py) listens for the shortcut;
         start_nightmare.ps1 starts it together with the backend.
         Press once: the window opens bottom-right, on top, focused. Hold Space
         (or the eye) to talk, or type. Press again while it's in front: it
         hides. Press again: it comes back where you left it.
         Change the shortcut with NIGHTMARE_HOTKEY in backend\.env
         (e.g. ctrl+alt+m, win+shift+f9) or turn it off with "off", then run
         .\scripts\start_nightmare.ps1 -Background.

Voice / Text Commands (in the small window):
  - Full view:     "home" / "go home" / "full screen" / "show everything"
                   (or the expand button). The window maximizes and stops
                   staying on top.
  - Small again:   "mini" / "small window" / "minimize", or press the shortcut.

Start at Windows log on (backend + shortcut helper):
  - .\scripts\install_autostart.ps1        (remove: .\scripts\uninstall_autostart.ps1)
